# Radial Network Restoration Simulator

A Java-based DSA case study for evaluating outage-restoration switching plans
in radial electrical distribution networks.

## Problem
Evaluate switching operations while preserving radial topology and tracking
disconnected customer demand.

## Data structure
Augmented Euler Tour Tree backed by an AVL-based sequence tree.

## Scope
- Dynamic network topology
- Cycle detection
- Disconnected-demand tracking
- Simplified electrical screening
- Local browser dashboard

## Limitations
This is an educational simulator, not a certified grid-control system.
Electrical screening is simplified and is not a complete AC power-flow study.
